# Logbook

This file is for the Light profile only.

Use it as a compact combined log for decisions, research notes, and hypotheses when a full multi-file structure would be too heavy.

For larger projects, split entries into:

- `DECISION_LOG.md`
- `RESEARCH_LOG.md`
- `HYPOTHESIS_LAB.md`

## Entry template

```md
## YYYY-MM-DD - Short title

- type: decision | research | hypothesis | note
- summary:
- context:
- result / decision / hypothesis:
- confidence:
- next action:
- should promote to current state?: yes | no | unsure
```
